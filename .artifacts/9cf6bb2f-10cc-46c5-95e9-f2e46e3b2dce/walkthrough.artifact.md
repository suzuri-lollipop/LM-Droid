# OpenAI TTS プロファイル登録機能の実装

音声合成プロファイルとして OpenAI API を登録し、アシスタントの返信を OpenAI の高品質な音声で読み上げられるようにしました。

## 変更内容

### 0. データベースバージョンの更新 (NEW)
- データベースのスキーマが変更されたため、`AppDatabase` のバージョンを **11** に上げました。これにより、古いスキーマとの不一致による強制終了が解消されます。
  > [!NOTE]
  > 現在、開発初期段階のため、バージョンアップ時に既存のチャット履歴等はリセット（破壊的マイグレーション）されます。

### 1. データモデルの拡張
- `ApiProfileEntity` に `PROVIDER_OPENAI_TTS` プロバイダータイプを追加しました。
- OpenAI TTS 特有の設定項目である「モデル（tts-1, tts-1-hd）」と「ボイス（alloy, echo, fable, onyx, nova, shimmer）」を保存するためのフィールドを追加しました。

### 2. OpenAI TTS クライアントの実装
- `OpenAiTtsClient` を新規作成し、OpenAI の `/v1/audio/speech` エンドポイントを呼び出して音声データ（MP3等）を取得する機能を実装しました。

### 3. プロファイル編集・管理機能
- `OpenAiTtsProfileEditScreen` と `OpenAiTtsProfileEditViewModel` を作成し、OpenAI TTS プロファイルの各設定（APIキー、ベースURL、モデル、ボイス）を編集できるようにしました。
- プロファイル追加ダイアログで OpenAI TTS を選択できるように更新しました。

### 4. 音声再生の統合
- `AssistSpeechPlayer` を更新し、選択されたプロファイルが OpenAI TTS の場合に `OpenAiTtsClient` を使用して音声を準備（prepare）するようにしました。

### 6. OpenAI TTS モデル・ボイスの動的取得 (NEW)
- OpenAI TTS 編集画面で、モデル名とボイス名をAPIから自動取得できるようにしました。
- 「接続テスト（オプション取得）」ボタンをタップすると、`/v1/models` および `/v1/audio/voices` から情報を取得し、ドロップダウンの選択肢に反映します。
- 取得したリストにない名前を使いたい場合に備え、テキストフィールドへの直接入力（タイピング）も可能にしました。
- TTS用のモデルがチャット画面のモデル選択肢に混ざらないよう、フィルタリングを強化しました。

## 確認方法

1. **プロファイルの追加**:
   - 「設定」→「API設定」→「＋」ボタンから「OpenAI TTS」を選択してプロファイルを作成します。
   - プロファイル名、OpenAI APIキーを入力し、必要に応じてモデルやボイスを選択して「保存」します。

2. **音声の選択**:
   - 「設定」→「音声」を開き、「使用する音声」から作成した OpenAI TTS プロファイルを選択します。

3. **読み上げの確認**:
   - デバイスのアシスタント（電源キー長押しなど）を起動し、音声で質問します。
   - アシスタントからの返信が、設定した OpenAI の音声で読み上げられることを確認してください。

## 補足
- OpenAI TTS はネットワーク経由で音声を合成するため、インターネット接続が必要です。
- 合成に失敗した場合は、自動的に端末標準の音声合成（TTS）にフォールバックします。
